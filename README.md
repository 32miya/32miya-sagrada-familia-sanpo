# サグラダ・ファミリアさんぽ

バルセロナのサグラダ・ファミリアを、スマホで歩いて巡る3D散策。
お城さんぽシリーズ・蝋人形館さんぽと同じ操作系（three.js r128・単一HTML）。

- 外観：生誕・受難・栄光の3つのファサード、18本の塔（イエス 172.5m・聖母マリア・4福音書記者・12使徒）、後陣
- 内部：枝分かれする樹の柱（斑岩・玄武岩・花崗岩・砂岩）、東の青緑と西の赤橙のステンドグラス、主祭壇と天蓋
- 地下聖堂とガウディの墓、生誕の塔のエレベーター（65mの橋）と螺旋階段
- まわり：アシャンプラの八角形の街区、ガウディ広場の池（映り込み）、サグラダ・ファミリア広場、付属学校
- とき：1926年（ガウディ没年）／現在（2026年）／完成予想、時刻：朝・昼・夕・夜（ライトアップ）
- 見どころ札集め（17か所・歩いて訪れたときだけ）、登塔の印、写真モード、合成音（街・鐘・堂内の和音）

方角は簡略化（生誕＝東、受難＝西、栄光＝南）。建物は簡略な再現で、「完成予想」は想像を含みます。
